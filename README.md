# 跑酷游戏（Console Parkour）

一个在 Windows 控制台运行的 C++ 跑酷小游戏，由 **sunnycl（人类开发者）** 与 **DeepSeek** 共同开发完成。  
sunnycl 负责整体设计、核心玩法、物理与碰撞、地图生成、交互逻辑与测试调优；DeepSeek 在代码整理、部分函数实现、注释与文档方面提供辅助。**人类贡献大于 AI 贡献。**

## 项目简介

- 纯 C++ / Windows 控制台游戏，无需图形库
- 支持多种难度：简单、普通、困难、地狱，以及从本地导入自定义地图
- 内置地图工坊，可自行编辑、保存、加载地图
- 支持回放录制与播放，可保存为 `.dat` 文件
- 包含新手教程，快速上手
- 仓库内的`map`文件夹，内含高难度地图，鼓励大家多多挑战

## 玩法介绍

这是一款在控制台中进行的横版跑酷游戏。你将操控一名角色，在充满平台与尖刺的关卡中不断前进，目标是在尽可能短的时间内抵达终点。途中可以移动、跳跃、二段跳，还能向左右冲刺来跨越较宽的间隙或躲避危险。尖刺有不同方向，只有从特定方向碰到才会受伤，而全方向尖刺则无论从哪边触碰都会致命。一旦死亡，角色会回到起点，并且总耗时增加五秒。游戏提供多种难度选择，也可以在地图工坊里自己设计关卡，或导入他人制作的地图。此外，你还能录制并回放自己的通关过程，方便分享或挑战极限。
